# 查机票价格

用最少步骤帮用户查清机票价格，并给出可读的对比结果。

## 何时使用

- 用户要查机票、航班价格、比价
- 用户给出出发地、目的地、日期，想知道大概多少钱
- 用户问某条航线单程/往返大概价位

## 必需信息

先收集这些字段；缺什么就问，不要猜日期：

| 字段 | 说明 | 示例 |
|------|------|------|
| 出发地 | 城市或机场 | 上海 / PVG |
| 目的地 | 城市或机场 | 东京 / NRT |
| 出发日期 | YYYY-MM-DD | 2026-08-15 |
| 行程类型 | 单程或往返 | 往返 |
| 返程日期 | 往返时必填 | 2026-08-22 |

可选（用户没说就用默认）：

- 乘客：1 成人
- 舱位：经济舱
- 币种：跟随用户语言（中文默认 CNY，英文默认 USD）
- 偏好：直飞优先 / 可接受转机 / 特定航司

信息不全时，一次问清缺失项，不要连环追问。

## 查询步骤

1. **确认行程**：用一句话复述（出发地 → 目的地，日期，单程/往返，舱位，人数）。
2. **搜索价格**：用 WebSearch / WebFetch 查公开比价信息。优先覆盖：
   - 国际：Google Flights、Kayak、Skyscanner
   - 国内/出境常见：携程、去哪儿、飞猪
   - 搜索词示例：`上海 东京 2026-08-15 机票价格`、`PVG to NRT flights Aug 15 2026 price`
3. **整理结果**：至少给出 3 个可对比选项（若搜到更少就如实说明）。每个选项尽量包含：
   - 价格（含币种）
   - 航司
   - 是否直飞 / 转机次数
   - 出发与到达时间（若有）
   - 总耗时（若有）
   - 来源网站
4. **标出推荐**：用一句话说明最便宜、最快、或性价比最高的选项，以及理由。

## 输出格式

用下面结构回复，保持简短：

```markdown
## 行程
上海 (PVG) → 东京 (NRT)｜2026-08-15 去 / 2026-08-22 回｜经济舱｜1 成人

## 价格对比
| 方案 | 价格 | 航司 | 航程 | 时长 | 来源 |
|------|------|------|------|------|------|
| A | ¥2,180 | 春秋航空 | 直飞 | 2h55m | 去哪儿 |
| B | ¥2,450 | 日本航空 | 直飞 | 2h50m | Google Flights |
| C | ¥1,980 | 多航司 | 1 次转机 | 6h20m | Kayak |

## 建议
最便宜是 C；若优先舒适/省时，选 B。

## 说明
- 价格为查询当时的公开参考价，下单前请再确认。
- 未含行李额、选座等附加费用（除非来源已写明）。
```

## 规则

- **先搜再答**：不要凭记忆编造票价；搜不到就说搜不到，并给出可手动打开的搜索链接思路。
- **单位一致**：同一张表里币种统一；必要时注明汇率仅供参考。
- **城市多机场**：像东京（HND/NRT）、上海（PVG/SHA）、伦敦（LHR/LGW）等，默认搜该城市主要机场，并在结果里标明实际机场。
- **日期灵活**：若用户说「大概八月中」而不是确切日期，先确认一个具体日期，或给出邻近 2–3 天的最低价趋势。
- **不替用户下单**：只比价与建议；不收集支付信息，不声称已锁定座位。
- **结果过时要提醒**：明确写出「价格会波动，以预订页为准」。

## 快速示例

用户：`帮我查下下周北京到深圳的机票`

你应：

1. 确认：出发日（下周哪一天）、单程还是往返、是否只要直飞
2. 搜索并输出价格对比表
3. 给出一句推荐
